# Guides

Player-facing manuals for Who Did It. They explain how to play; the rules and every number live in
[`docs/GDD.md`](../GDD.md), which these guides reference and never restate.

**Play now:** [https://groot99-droid.github.io/Who-Did-It/](https://groot99-droid.github.io/Who-Did-It/). The same
guides are served beside the game at [`/Who-Did-It/help/`](https://groot99-droid.github.io/Who-Did-It/help/).

| Guide                                | For                                                                                   |
| ------------------------------------ | ------------------------------------------------------------------------------------- |
| [How to play](HOW_TO_PLAY.md)        | A first match of the main mode: controls, phases, clues, meetings, roles, winning.     |
| [Host guide](HOST_GUIDE.md)          | Making a party, inviting friends, the lobby settings, what to do when something sticks. |
| [Admin guide](ADMIN_GUIDE.md)        | The owner's auto-mode page and the headless runner, for finding bugs.                 |

The design documents are indexed in [`docs/README.md`](../README.md).
