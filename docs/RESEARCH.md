- **Phaser lighting (moody noir)** [high]: Phaser 3: `this.lights.enable(); this.lights.addLight(x,y,radius,rgb,intensity); gameObject.setPipeline('Light2D')`; normal map loaded via `this.load.image(key, [url, normalMapUrl])`; `this.lights.setAmbientColor(0x...)`. Phaser 4 replaces the pipeline call with `gameObject.setLighting(true)` (Lighting component, WebGL only), adds explicit light `z` height (`addLight(x,y,radius,rgb,intensity,z)`), `setSelfShadow(enabled, penumbra, diffuseFlatThreshold)` and game-wide `config.render.selfShadow`. Point Lights (`this.lights.addPointLight`) are cheap, don't use normal maps, good for torches/flicker. Lights cannot live inside Containers.  
  Source: https://docs.phaser.io/api-documentation/namespace/gameobjects-components-lighting ; https://docs.phaser.io/api-documentation/4.0.0/class/gameobjects-lightsmanager ; https://docs.phaser.io/phaser/concepts/gameobjects/light
- **Phaser scene lifecycle** [high]: ScenePlugin: `scene.start(key,data)` shuts down current and runs target; `launch(key,data)` runs target in parallel; `sleep()/wake()` keep objects without update/render; `pause()/resume()`; `switch(key)` = sleep current + start/wake target; `run()` = start/wake/resume; `stop()`. All transitions are deferred to the next Scene Manager update. Scene states: PENDING, INIT, START, LOADING, CREATING, RUNNING, PAUSED, SLEEPING, SHUTDOWN, DESTROYED. Pattern for house interiors: keep a persistent HUD/UI scene via launch, and use sleep/wake (or start) for Overworld <-> Interior scenes.  
  Source: https://docs.phaser.io/api-documentation/class/scenes-sceneplugin ; https://docs.phaser.io/phaser/concepts/scenes ; https://docs.phaser.io/api-documentation/4.0.0/namespace/scenes

- **@colyseus/schema API** [high]: Two equivalent definition styles in Schema 5: decorators (`class Player extends Schema { @type("string") name: string; @type({ map: Player }) players = new MapSchema<Player>(); @type([Player]) list: ArraySchema<Player> }`, needs `experimentalDecorators: true` + `useDefineForClassFields: false` in tsconfig) or the decorator-free builder (`const Player = schema({ name: t.string(), x: t.number() }, "Player"); type Player = SchemaType<typeof Player>; const State = schema({ players: t.map(Player), list: t.array(Player) }, "State")`). `@type()` validates primitive types at write time (EncodeSchemaError). MapSchema supports set/get/getOrInsert/delete/size/toJSON. `defineTypes()` is the legacy JS-only style.

- **Colyseus StateView (interest management / hidden info)** [high]: Per-client filtering exists since 0.16 via `StateView` + `@view()`: in `onJoin` set `client.view = new StateView(); client.view.add(player)`. A whole collection can be tagged (`@view() @type({ map: Player }) players` / `t.map(Player).view()`) so each client only sees items added to its view (frontend receives them as onAdd/onRemove). Ideal for secret roles, killer identity, per-room (house interior) visibility.

### Recommendations

- Engine pin: the owner's 'Phaser 3' decision predates Phaser 4's April 2026 release. Recommend starting on phaser@4.2.1 (official guidance says no reason to start new projects on 3; scenes/tilemaps/cameras/physics APIs are identical for this project's needs; lighting is `setLighting(true)` instead of `setPipeline('Light2D')`). If the orchestrator insists on 3.x, pin phaser@3.90.0 and avoid Phaser-4-only features (Filters, TilemapGPULayer, PCT atlases). Either way, treat the top-down 2.5D + TypeScript + Vite decision as unchanged.
- Server pin: colyseus@^0.18.9 / @colyseus/core@^0.18.18 / @colyseus/schema@^5.0.36 / @colyseus/sdk@^0.18.5 / @colyseus/testing@^0.18.6 on Node 22 (engines require >= 22). Do NOT install `colyseus.js` (legacy 0.16). Scaffold with `npm create colyseus-app@latest apps/server -- --ts --netcode fixed --matchmaking lobby,reconnection --yes`.
- Define state with the Schema 5 builder (`schema({...}, "Name")` + `t.*`) in a shared workspace package instead of decorators; this removes the experimentalDecorators/useDefineForClassFields tsconfig coupling and lets the Phaser client and Colyseus server import the same definitions. Keep each Schema under 63 fields (nest sub-schemas for inventory, role, position).
- Hidden-role integrity: keep role, killer identity, secret inventory and per-house visibility in `@view()`/`.view()` fields and tagged collections; assign `client.view = new StateView()` in onJoin and add/remove entities as players enter/leave interiors. Role cards are then delivered only to their owner by construction, not by client-side filtering.
- Party flow: implement the official Custom Room ID recipe (4-letter A-Z code via presence set) for `Create Party`; mark the room `private` so `joinOrCreate` never lands strangers in it; `Join Party` calls `client.joinById(code)`; call `this.lock()` on Start so late joins are refused. Persist `room.reconnectionToken` in sessionStorage and call `allowReconnection(client, 60)` in `onDrop` so a tab reload during a round keeps the seat.
- Tick/patch: use `setFixedTimestep(step, 20)` (20 Hz input/sim, optionally subSteps:2 for 40 Hz physics) with default patchRate 50 ms for a 4-10 player top-down party game; on the client use `Predict.get(room, { mode: 'lerp', delay: 100 })` + `attachAll('players', ...)` for remote players, `reckon` for creatures/NPCs, and the reconciler for the local player. Skip third-party snapshot-interpolation libs since 0.18 ships this.
- Hosting path: dev/playtests on Render Free (accept ~1 min cold start; show a 'waking server' state in the landing page and poll a /health route before enabling Create/Join; in-game WebSocket traffic keeps it alive since Feb 2026). For real sessions move to Railway Hobby ($5/mo, always-on; small server fits the included usage), Fly shared-cpu-1x 512 MB (~$3-5/mo), or Colyseus Cloud High Frequency (from $15/mo, zero-ops wss). Skip Koyeb (free web service no longer visible) and Glitch (hosting ended Jul 2025). Keep a single Colyseus process; horizontal scaling needs Redis presence/driver and sticky sessions.
- Client/server contract across origins: client reads the server URL from `import.meta.env.VITE_SERVER_URL` (https://...), set as a GitHub Actions variable; server restricts `matchMaker.controller.DEFAULT_CORS_HEADERS['Access-Control-Allow-Origin']` to https://groot99-droid.github.io (and localhost in dev). Always https/wss; ws:// fails on GitHub Pages (mixed content) and on Render (301).
- GitHub Pages: `base: '/Who-Did-It/'` in vite.config.ts, hash-based routing for /#/join/ABCD deep links, workflow with actions/checkout@v7, setup-node@v7 (node 22, pnpm via corepack or pnpm/action-setup), configure-pages@v6, upload-pages-artifact@v5 (path ./apps/client/dist), deploy-pages@v5, Pages source = GitHub Actions. Set Phaser loader paths relative to `import.meta.env.BASE_URL`.
- Repo layout: pnpm workspace monorepo with packages/shared (schemas, rules engine, constants, map/world data for V2 reuse), apps/client (Phaser + Vite), apps/server (Colyseus). Tests: Vitest 5 for shared rules (pure functions: role assignment, vote resolution, win conditions), @colyseus/testing + Vitest for room flows (create -> join by code -> start -> role card message -> vote), Playwright 1.64 for a browser smoke test against the built client (landing renders, Create Party shows a 4-letter code). Pin TypeScript 5.9.x/6.0.x (not 7.0) until the 7.1 programmatic API lands so typescript-eslint and editor tooling keep working.
- Art pipeline: render characters/props from Blender to 8-direction sheets AND a matching normal-map pass so `setLighting(true)` produces real per-pixel shading under the noir lights; use Point Lights for cheap torches/flicker and a dark `setAmbientColor`. For in-world VFX, render AE comps to PNG sequences and pack them as Phaser animations.

### Gotchas

- Phaser docs are mixed-version: the 'Light' concept page still documents `setPipeline('Light2D')` (Phaser 3) while the 4.x API docs use `setLighting(true)`; check the API-reference version selector before copying snippets.
- phaserjs/template-vite-ts still ships Vite 6.3.1 / TS 5.7.2; bump to Vite 8.x (requires Node ^20.19 || >=22.12) after scaffolding. The template's `dev`/`build` scripts call an anonymous log.js; use the `-nolog` variants or strip it.
- `colyseus.js` on npm is dead (0.16.22, Oct 2025). Most tutorials (including the official Phaser + Colyseus tutorial) are written for 0.15/0.16 (`room.state.players.onAdd`, `new Server()`, `onLeave(client, consented)`); translate to `@colyseus/sdk`, `Callbacks.get(room)`, `defineServer/defineRoom`, `onLeave(client, code)`.
- Colyseus 0.18 breaking: `setMetadata()`/`setMatchmaking({ metadata })` now replace the whole metadata object (spread `this.metadata` to merge); `client.id` removed; max 63 fields per Schema (inherited fields count); fossil-delta serializer removed; playground returns 404 in production unless a `use` guard is passed.
- Decorator-based schemas need `experimentalDecorators: true` and `useDefineForClassFields: false` in BOTH client (Vite/esbuild reads tsconfig) and server tsconfigs; missing `useDefineForClassFields:false` silently breaks change tracking. The `schema()` builder avoids this entirely.
- TypeScript 7.0.x (now npm `latest`) has no stable programmatic API; typescript-eslint/ts-jest/ts-morph break until 7.1. Pin typescript to a 5.9.x/6.0.x release explicitly, because `pnpm add -D typescript` will pull 7.x.
- Vitest 5 requires Node ^22.12; Colyseus 0.18 requires Node >= 22. Set `engines.node: ">=22.12"` and a `.nvmrc`/`.node-version` of 22 so GitHub Actions and hosts match.
- Render Free: ~1 minute cold start on first connect; idle timer is 15 minutes of no HTTP and no inbound WebSocket messages, so a party lobby that sits idle (no messages) longer than 15 minutes gets its server killed and all rooms disposed (state is in-memory). Free Postgres expires after 30 days (not needed here). Do not rely on it for scheduled play sessions.
- Fly.io has no free tier anymore (7-day/2-hour trial, card required); 256 MB Machines are tight for Node + Colyseus; budget 512 MB. Railway requires a post-paid card and bills metered usage beyond the $5 Hobby credit.
- GitHub Pages serves only static files: no server-side routing, so path-based deep links 404 unless you use hash routing or the 404.html redirect hack; project-page assets must be loaded relative to `/Who-Did-It/` (Vite `base`), including Tiled JSON, atlases and any hard-coded Phaser loader paths.
- Phaser atlases do not support rotated frames; disable `allowRotation` in free-tex-packer-core (defaults to true) and in TexturePacker. Phaser's multiatlas loader expects the TexturePacker 'Phaser 3' JSON layout with a `textures` array; verify free-tex-packer-core's 'Phaser3' exporter output against `this.load.multiatlas` before committing to it.
- Phaser 4 TilemapGPULayer is orthographic-only with a single tileset per layer; keep interiors/overworld as orthographic Tiled maps (fine for top-down 2.5D) or fall back to the regular TilemapLayer for multi-tileset layers.
- A Lottie DOM overlay blocks Phaser pointer input; set `pointer-events: none` on the overlay (or confine pointer-events to its buttons) and destroy players (`lottie.destroy`) when scenes change to avoid leaks.
- Colyseus `allowReconnection` only helps if the client stores the reconnection token across reloads; the automatic reconnection (0.17+) covers network blips but not a full page reload. RelayRoom's `allowReconnectionTime` is clamped at 40 s.
- Colyseus default CORS is `Access-Control-Allow-Origin: *`; tighten it before launch, and remember `onAuth`'s `context.req` is only available on `static onAuth` (matchmaking HTTP request), not the per-connection one.
- The Colyseus netcode (`Predict`, `setFixedTimestep`, `room.input`) demos' full source is gated to GitHub sponsors; the docs pages (netcode/*, netcode/recipes) are public and sufficient, but expect to write the deterministic step function yourself.

### Facts

- **Blender version** [high]: Current LTS is Blender 5.2 LTS (initial release 14 July 2026, patched to 5.2.2 on 15 Sep 2026, supported until July 2028). Blender 4.5 LTS (July 2025, now 4.5.14) is still maintained in parallel; 5.1 shipped 17 Mar 2026. Pick 5.2 LTS for the pipeline; keep 4.5 LTS only if an add-on has not caught up.  
  Source: https://www.blender.org/releases/5-2/ ; https://www.blender.org/download/lts/
- **Blender toon shading (Shader to RGB)** [high]: The Shader to RGB node is 'EEVEE Only' and is the documented way to build a toon shader (BSDF -> Shader to RGB -> Color Ramp). Manual warns it breaks the PBR pipeline: upstream BSDFs become invisible to Screen Space Reflection, Subsurface Scattering, Alpha Clip/Hashed blend modes, and it does not give expected results in render passes. EEVEE was fully rewritten in 4.2 LTS ('EEVEE Next' is simply 'EEVEE' from 4.2 on).  
  Source: https://docs.blender.org/manual/en/4.5/render/shader_nodes/converter/shader_to_rgb.html ; https://developer.blender.org/docs/release_notes/4.2/eevee/
- **Blender outlines (Freestyle / inverted hull)** [high]: Freestyle is an edge/line NPR engine enabled under Properties > Render > Freestyle, configured per View Layer (view map -> line sets -> line styles), render-time only (not in viewport). Inverted-hull outlines (Solidify modifier with negative thickness, flipped normals, backface-culled emission material) work in both EEVEE and Cycles and in the viewport, which makes them easier to preview for batch sprite renders. Third-party kits (e.g. NPR Shader Kit) auto-detect EEVEE on 4.2+.  
  Source: https://docs.blender.org/manual/en/4.5/render/freestyle/introduction.html ; https://superhivemarket.com/products/npr-shader-kit--stylized-rendering/docs
- **Blender transparent PNG frame output** [high]: EEVEE Film panel has 'Transparent' (render background as alpha) plus Filter Size (lower = crisper edges, useful for small sprites) and Overscan. Render animation to a PNG RGBA sequence with Film > Transparent, then pack frames externally.  
  Source: https://docs.blender.org/manual/en/4.5/render/eevee/render_settings/film.html

  Source: https://blenderartists.org/t/creating-an-isometric-camera/440743 ; https://wiki.blender.jp/Extensions:2.6/Py/Scripts/Add_Mesh/Create_IsoCam ; https://polycount.com/discussion/comment/1909167

### Recommendations

- Standardise on Blender 5.2 LTS (supported to July 2028) with EEVEE; build the toon look as Principled/Diffuse BSDF -> Shader to RGB -> Color Ramp (2-3 bands) + Emission rim, and use an inverted-hull Solidify outline rather than Freestyle so outlines preview in the viewport and batch-render identically in every direction; disable SSR/SSS/alpha-hashed materials on characters because Shader to RGB breaks them.
- Camera rig: one orthographic camera at X=60°, Z=45° (2:1 dimetric; switch to 54.736° only if you want true iso tiles), parented turntable Empty rotated in 45° steps for 8 directions, Film > Transparent, Filter Size ~1.0-1.2, fixed key light parented to the camera so lighting is identical across directions. Render each action to PNG sequences at 256 px, then downscale to the shipping 96-128 px frame size for crisp anti-aliased edges.
- Automation: start with the official 'Sprite Sheet Generator' extension (free, GPL, Blender 5.x-tested) for proof of concept; if its 4-direction armature rotation is limiting, use AUTeddy 8-Directions (v2, Blender 5.0+, $5) for per-direction folders and do packing in the repo with free-tex-packer-core, or buy Blaterna Studio ($19.90) if you want colour + normal-map passes for Phaser Light2D. Keep a small Python bpy script in tools/ that sets render settings so renders are reproducible from CI-free local runs.
- Animation sourcing: Mixamo (free, commercial OK, no credit) for the base locomotion set (idle/walk/run/death/carry); import FBX into Blender with the 'Mixamo Rig' extension or Mixaify when you need Rigify controls to author custom interact/attack poses; budget Cascadeur Indie ($96/yr) only if hand-keyed physics-based actions are needed (free tier cannot export FBX).
- Character bodies: author 4-6 chunky low-poly bodies and get 10 player variants via palette/tint (Phaser setTint or a 1D palette-LUT shader) plus role-specific accessory sprites rendered as separate 8-direction overlay sheets; this keeps the atlas count at roughly one 2048^2 page per body and the initial download under 20 MB.
- Asset library policy for the public repo: allow CC0 only by default (Poly Haven, Kenney incl. Kenney audio + UI, KayKit, Freesound CC0 filter, Pixabay under its own license); allow CC-BY (Sketchfab CC-BY, Freesound CC-BY, Meshy free-plan output) only with an entry in CREDITS.md listing title, author, URL and license; ban CC-BY-NC, CC-BY-ND, Quaternius QAL source packs (ship only rendered sprites derived from them, not the FBX/GLB), and all Synty content. Add a LICENSES/ folder with the CC0/CC-BY texts and a .gitattributes/LFS rule for .blend and large source files.
- Higgsfield usage: use Soul Cast / 3D Jutsu Angles for consistent character concept + turnaround sheets, Nano Banana 2 or Seedream 5.0 Pro (remove_bg) for decals/texture tiles/UI icons, Recraft V4.1 vector mode for icon sets, AutoSprite Animation for throwaway prototype sprites (iso presets) before Blender assets exist, and image_to_3d/meshy_v7 (lowpoly, quad, a-pose, rigging) to block out props/creatures that are then cleaned in Blender. Do it on a paid plan to avoid watermarks, and never upload Synty or other restricted models to it.
- Adobe pipeline: Illustrator Export for Screens at 1x/2x PNG (and SVG for crisp scaling) for UI, role cards and icons; After Effects + Bodymovin for role-card reveal animations played through lottie-web in a DOM overlay with pointer-events:none, or exported as PNG sequences into a Phaser atlas if you want everything inside the canvas; Photoshop for atlas cleanup and normal-map touch-ups; Firefly generative fill only for texture/decal patches and only with Adobe's own Firefly model (not partner models) if you want the 'commercially safe' posture; skip Substance 3D (separate $24.99-$59.99/mo subscription) unless hand-painted stylised textures become a bottleneck.
- Audio: Kenney audio + Freesound CC0 for SFX, Pixabay for music stingers, Audacity 4.0.1 for trimming/normalising to short OGG/MP3; for role-card narration use ElevenLabs Starter (commercial license) or Higgsfield generate_audio, never the ElevenLabs free tier, and store generated voice lines as CC0-equivalent project assets with a note of the generator in CREDITS.md.
- Budgets to encode in the build (Vite + pnpm): atlas pages max 2048x2048 PNG (power-of-two, trimmed, rotation allowed), optional ASTC/ETC2/S3TC variants in PVR/KTX containers loaded via this.load.texture with PNG fallback; initial payload (engine + lobby + role cards + first map + one body atlas) <= 15 MB, everything else lazy-loaded per scene; total site well under GitHub Pages' 1 GB and the 100 GB/month soft bandwidth limit.

### Gotchas

- Quaternius assets are no longer CC0: the QAL v1.0 forbids redistributing the raw assets, so committing their FBX/GLB packs to the public repo is a violation even though shipping rendered sprites is fine.
- Synty EULA (9 July 2026 text) bans sharing source files outside your team and uploading models to 3D-generation services; a public GitHub repo containing Synty files breaches it, and using Synty models as Higgsfield/Meshy inputs is explicitly prohibited.
- Mixamo's only hard rule is no redistribution of raw character/animation files, but a public repo containing downloaded Mixamo FBX files is exactly that; keep Mixamo FBX out of the repo (gitignore or private LFS) and commit only the rendered sprite sheets and your own .blend rigs.
- Sketchfab's free CC downloads were announced to end after the Fab migration; CC0/CC-BY-SA/NC/ND models cannot move to Fab. Download and license-record anything you want now, and respect per-model licenses (CC-BY needs credit, ND forbids re-rendering/edits, NC breaks any future monetisation).
- Shader to RGB is EEVEE-only and makes upstream BSDFs invisible to screen-space reflections, subsurface scattering and alpha clip/hashed modes; it also misbehaves in render passes, so render normal/ID passes from a separate material or use Blaterna's layer system.
- Freestyle lines are render-only (no viewport preview) and are computed per frame, so they can flicker between directions/frames on tiny sprites; inverted hull is more stable for 64-128 px output.
- Mirroring E/NE/SE from W/NW/SW saves 37.5% of frames but flips carried items and directional (noir) lighting; with a side key light the mirrored sprites will look lit from the wrong side, so either render all 8 directions or keep the key light front/top-centred.
- Blender 5.x removed the built-in COLLADA (.dae) importer; kits that only ship DAE need an add-on or conversion in 4.5 LTS. Prefer GLB/FBX downloads (Kenney recommends GLB).
- Android still has a meaningful share of devices with MAX_TEXTURE_SIZE 4096 and ~25% below 8192 per Web3D Survey; a single 4096^2 atlas also costs 64 MB VRAM uncompressed. Use 2048^2 multi-atlas pages and query getMaxTextureSize() at runtime.
- Phaser's compressed-texture loader only reads KTX v1 and PVR containers (no KTX2/Basis), PVRTC needs power-of-two + linear colour, and Light2D requires atlases (spritesheets with normal maps have been reported to vanish).
- ElevenLabs free tier is non-commercial and requires an 'elevenlabs.io' credit even for free publishing; commercial rights need a paid plan and cloned voices need the owner's consent. Higgsfield free-plan output may be watermarked.
- Adobe Firefly's 'commercially safe' claim and indemnity apply to Adobe's own Firefly models; partner models (Google, OpenAI, Runway, etc.) inside Firefly are not trained to Adobe's standards and indemnity coverage for them is unconfirmed. Adobe helpx pages return 403 to automated fetches, so re-read the Generative AI Additional Terms manually before release.
- Many 2026 'free asset' guides (cinevva and similar) are marketing content that still label Quaternius as CC0 and overstate Mixamo/Sketchfab status; always confirm on the vendor's own license page and keep a dated copy of the license text in the repo.
- Freesound license filter only exposes 'Free Cultural Works' (CC0 + CC-BY) as a group; CC-BY sounds still need per-file credit, so use freesound.org/home/attribution/ to generate the CREDITS entries.
- GitHub Pages is explicitly not allowed as a host for primarily commercial services; a free hidden-role game is fine, but any future paid cosmetics/ads would need the client moved to another static host.
