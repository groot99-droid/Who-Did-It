## Server to client

| Type | Payload | Notes |
|---|---|---|
| `roleReveal` | `RoleRevealPayload` | Private. |
| `sceneEnter` | `{ sceneId: string; spawn: string; facing: string }` | Private. |

| `killed` | `{ sceneId: string; cause: DeathCause; roles: Record<string, string> }` | Private: the player is now a ghost; `roles` lists every seat's role id (ghosts see all roles, GDD 3.7). |
| `chat.msg` | `{ from: string; text: string; channel: ChatChannel }` | Private: routed per recipient; `from` is a player id. |
| `phaseChange` | `{ phase: number; endsTick: number }` | - |
| `meetingStart` | `{ reason: MeetingReason; callerId: string; bodyOf?: string; missing: string[] }` | - |
| `voteResult` | `{ tally: Record<string, number>; ejectedId?: string; role?: string; outs?: string[]; roles?: Record<string, string>; abstained?: string[]; }` | `tally` counts votes per target id and `"skip"`; voters are never named (GDD 3.8). Quick mode: `outs`, their final roles and the seats that did not vote (3.11). |
| `gameOver` | `{ winner: number; roles: Record<string, string>; summary: string; onub?: OnubGameOver }` | `roles` are the final roles; `onub` is present in quick mode only (A39). |
| `noise` | `{ sceneId: string; x: number; y: number; kind: string }` | - |
| `error` | `{ code: ErrorCode; msg: string }` | - |
| `nightWake` | `{ windowRole: string; endsTick: number; spawn: string }` | Private, quick mode: your window opened; you stand at `spawn` in the bakery until `endsTick` (GDD 3.11). |
| `nightReveal` | `{ entries: NightRevealEntry[] }` | Private, quick mode: what your act showed. |
| `nightSleep` | `Record<string, never>` | Private, quick mode: back to the loft. |

"Private" messages are sent to their owner only; no private payload is broadcast.

## Error codes

`error {code, msg}` carries one of these inside a room.

| Code | Name |
|---|---|
| 422 | `cannot` |
| 423 | `locked` |
| 424 | `cooldown` |
| 425 | `wrongPhase` |
| 426 | `busy` |
| 427 | `outOfRange` |
| 428 | `closed` |

## Join errors

Every `joinById` failure (missing, locked, full, version mismatch, bad name) returns the same error: code 404, message "party not found or unavailable".
