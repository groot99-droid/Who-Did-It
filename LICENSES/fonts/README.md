# Font licences

Both fonts are SIL Open Font License 1.1 and are self-hosted (no CDN) from
`apps/client/src/assets/fonts/`: the Latin subset of each variable font, taken unmodified
from the Fontsource packages `@fontsource-variable/oswald` 5.3.0 and
`@fontsource-variable/inter` 5.3.0.

| Font | Use | Licence text |
|---|---|---|
| Oswald (variable, wght) | Headings, role names, the party code | `OFL-Oswald.txt` |
| Inter (variable, wght) | Body and controls | `OFL-Inter.txt` |
