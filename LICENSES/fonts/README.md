# Font licences

All seven fonts are SIL Open Font License 1.1 and are self-hosted (no CDN) from
`apps/client/src/assets/fonts/`: the Latin subset of each, taken unmodified from the Fontsource
packages `@fontsource-variable/oswald` 5.3.0, `@fontsource-variable/inter` 5.3.0,
`@fontsource-variable/pixelify-sans` 5.3.0 and `@fontsource/press-start-2p` 5.3.0 (Press Start 2P
has one weight and no variable build). Round 10's three (A257) are `@fontsource/alegreya-sc`, `alegreya-sans` and
`ibm-plex-mono` 5.2.5, one file per weight, under one OFL text with their three copyright lines.

| Font | Use | Licence text |
|---|---|---|
| Oswald (variable, wght) | Headings, role names, the party code (paper screens) | `OFL-Oswald.txt` |
| Inter (variable, wght) | Body and controls; the role card's and the notebook's running text | `OFL-Inter.txt` |
| Pixelify Sans (variable, wght 400 to 700) | Text on the night theme's glass surfaces (docs/UI.md 3, round 7) | `OFL-PixelifySans.txt` |
| Press Start 2P (400) | The title, the party code and button labels on the night theme (docs/UI.md 3, round 7); Reserved Font Name "Press Start 2P" | `OFL-PressStart2P.txt` |
| Alegreya SC (700) | Section heads and the role name on the role card and the Satchel (docs/UI.md 3, round 10) | `OFL-Dossier.txt` |
| Alegreya Sans (400, 500, 700) | Running text, buttons and pills on the role card and the Satchel | `OFL-Dossier.txt` |
| IBM Plex Mono (400, 500) | Eyebrows, keys, numbers and chips on the role card and the Satchel; Reserved Font Name "Plex" | `OFL-Dossier.txt` |
